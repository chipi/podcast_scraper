# v2.7 signal triage (2026-08-27)

30 open v2.7 issues, triaged as **signals** (mostly GlitchTip auto-filed by the "triage-fleet MVP"). For each: a **class** and an **action**. The recurring shape is *an expected condition (external API hiccup, cost cap, missing index, LLM truncation) raised as an UNHANDLED error → logged at ERROR → GlitchTip auto-files it*. Fixing the **handling + log level** both resolves the issue and stops the noise.

## Classes
- **FIX** — real code defect, fix at cause.
- **HANDLE** — expected/external condition leaking as an uncaught error; catch it, degrade gracefully, log at WARNING/INFO. (Fixes *and* curves the noise.)
- **CURVE** — working-as-designed; the only change is log-level (ERROR→WARN/INFO) and/or dedup so GlitchTip stops firing. No behavior change.
- **TUNING** — a threshold/config tradeoff; needs an operator decision.
- **OPS/ENV** — environment/infra or a transient external outage, not app logic.
- **DEFER** — deep (native crash) or low-signal single occurrence.
- **UX** — genuine product bug from the spec-drift audit (not GlitchTip noise; a separate real workstream).

## Systemic feedback-loop fixes (the meta-win)

1. **Handle expected external conditions at the boundary, log at WARNING.** #1864, #1529, #1480, #1409, #1564 all leak an *uncaught* error for a condition the pipeline should expect. A small shared pattern (catch → degrade → WARNING with a clear message) fixes a cluster at once and stops the ERROR-level auto-filing.
2. **Fix the auto-filer dedup.** The triage-fleet MVP already stamps a stable `fp: glitchtip:PODCAST-…` fingerprint on every issue, yet it filed #1861/#1866 as NEW during our cleanup. Point it at the fingerprint so a recurring signal UPDATES the canonical issue instead of spawning duplicates. Highest-leverage single change.
3. **Log level should track recoverability, not intent** (the #1556 principle, already applied there): a handled/recoverable degradation = WARNING; only a terminal, unrecoverable loss = ERROR. Apply consistently so GlitchTip only fires on genuine losses.
