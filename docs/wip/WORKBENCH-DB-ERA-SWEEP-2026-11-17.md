## "Now" and the news release

After the advisor's review of the merged sweep (the database session, 2026-11-17):

- **R16 is R3b scope, in the news release.** R3b changes GI's show id from the title slug to KG's
  id (`podcast:sha256…`); on that day the show node page matches nothing and goes blank. The private
  viewer has three such places, and all join R3b's parity check. The fix ships before R3b: the API
  returns the show id beside the title, or R3b's old-to-new id map is served as a read (the read is
  Common's to name).
- **R12 is dropped.** NULL instead of 0.0 would rewrite every insight row in the index, against the
  no-full-rebuild rule, and change nothing visible: `context_pack.py` already shows 0.0 as "n/a".
  E09 retires the column.
- Nothing else found blocks the news release: UXS-019's news card and search row read neither the
  graph nor the confidence column.
